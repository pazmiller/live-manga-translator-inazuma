# Inazuma

**简体中文** | [English](README.en.md)

Windows 屏幕漫画翻译工具：框选正在阅读的漫画，在本地识别文字，再通过你选择的 AI 服务翻译。译文可显示在原气泡位置，也可作为可拖动的旁注，无需导入整本漫画或切换阅读软件。

- **选区翻译**：支持日文、英文、中文、韩文识别，逐条显示译文。
- **两种显示方式**：智能贴合原气泡，或保留原文、显示编号旁注。
- **日文加强识别**：可选 Manga OCR，重新精读已识别的气泡截图。
- **AI 配置窗口**：目前支持OpenAI、Gemini、DeepSeek，支持同步可用模型和手动填写模型名。
- **阅读与校正**：原文对照、单条编辑、字号调整、翻页检测及中英文界面。

## 安装

面向 Windows x64。使用安装包时，无需安装 Node.js、Python 或单独启动后端；AI 翻译需要联网和你自己的服务商 API Key。

| 版本 | 适合谁 | 包含内容 | 已构建的 1.2.1 安装包 |
| --- | --- | --- | --- |
| 标准版 | 希望安装体积较小、使用普通 OCR | Python 运行时、普通 OCR 及模型 | `Inazuma-Setup-1.2.1-x64.exe`，约 210 MiB |
| MangaOCR 完整版 | 需要日文气泡加强识别 | 标准版内容，以及 Manga OCR、CPU 推理运行时和模型 | `Inazuma-MangaOCR-Setup-1.2.1-x64.exe`，约 761 MiB；解包载荷约 1.79 GiB |

运行对应安装程序，安装后从桌面或开始菜单打开 **Inazuma** / **Inazuma MangaOCR**。安装包尚未代码签名，Windows 可能显示未知发布者。

**1.2.1 更新：** 两个安装包包含本地后端认证、Electron 窗口保护、窗口移动与截图修复，并清理了闲置翻译依赖。MangaOCR 完整版已采用新版 PyTorch / Transformers CPU 运行时。安装包与 SHA-256 校验文件见 [GitHub Releases](https://github.com/pazmiller/live-manga-translator-inazuma/releases)。旧 1.1.0 安装包不包含这些后续改动。

从源码运行或自行打包，见 [开发文档](docs/DEVELOPMENT.md)。

## 第一次使用

1. 打开 **翻译AI配置**，选择 OpenAI、Gemini 或 DeepSeek。
2. 选择模型，填入该服务商的 API Key，点击 **保存并使用**。API 地址自动匹配，无需编辑 `.env`。
3. 拖动选区边框和四角，框住需要翻译的漫画；主操作面板可通过顶部标题区域单独移动。
4. 选择源语言与目标语言，点击 **翻译选区**，或按 `Ctrl+Shift+T`。
5. 识别位置先显示虚线，译文准备好一条就显示一条。再次点击主按钮可取消当前任务。

三家服务商分别保存模型和密钥。再次打开配置时，密钥栏会留空；**留空保存表示继续使用已保存的密钥**，只换模型不需要重填。

预设模型不是持续自动更新的。“同步可用模型”会读取该服务商返回的账户模型列表；也可以选择“手动输入模型名称…”。同步成功不代表账户对每个模型都有调用权限或额度。

## 阅读与校正

**智能贴合**：背景合适且译文能放下时，在原气泡位置显示；背景复杂或文字过长时改用编号旁注。**全部旁注**：保留原漫画文字，适合复杂画面或较长译文。

| 操作 | 效果 |
| --- | --- |
| **A− / A+** | 调整译文字号，放不下时自动改用旁注 |
| **原图** / `Ctrl+Shift+O` | 临时隐藏译文，再次操作恢复 |
| 拖动译文 | 移动译文位置；原位译文会转为旁注 |
| 双击译文 / **原文** | 在 OCR 原文和译文之间切换 |
| **编辑** | 查看保存的气泡裁片，修正识别文字，再翻译并保存 |
| **清除** / `Ctrl+Shift+C` | 取消任务并清空译文 |
| **补译剩余 / 恢复上一版** | 处理部分失败的翻译；补译使用原任务的截图与配置 |
| **固定 / 翻页检测** | 检测画面变化并隐藏旧译文，稳定后由你点击“翻译新页” |
| **锁定选区** | 切换选区空白部分是否接收点击，面板和译文仍可操作 |
| **通透 / 柔和** | 调整面板外观，复杂画面下可使用柔和模式提高对比度 |
| **EN / 中文** | 切换界面语言，不改变漫画原文、译文或翻译语言 |

长译文可在卡片内滚动阅读，右上角 × 可关闭单个结果。退出按钮需要在 3 秒内点击两次确认。界面语言、翻译语言、字号和显示偏好会记住。

### 加强 OCR 与日漫精读

日文选区完成普通翻译后，点击主面板的 **加强 OCR**，使用 Manga OCR 精读本次截图中已找到、仍显示的气泡。原文变化的气泡会重新翻译，全部成功后一起更新；失败时保留已有结果。

只想修正单条，可打开气泡 **编辑 → 日漫精读**。它将识别结果填入原文框，核对后再点击 **翻译并保存**。原文修改后，旧译文会标为尚未重新翻译。

Manga OCR 仅用于日文，需要完整版或额外的开发环境。它复用普通 OCR 已找到的气泡位置，**不能补回普通 OCR 完全漏掉的气泡**。模型在启动后后台预热并常驻；载入和识别耗时取决于电脑配置。

## 隐私与数据

- OCR 在本地运行。翻译时，提取的文字发送给你选择的 AI 服务商；服务商调用可能产生费用。
- API Key 使用 Windows DPAPI 加密保存，不向配置窗口回填明文。普通用户无需创建 `.env`。
- 最近最多三次选区截图保存在应用内存中，用于气泡校正；清除或退出会释放。截图过期的旧译文需要重新框选。
- 旧开发版 `.env` / 旧安装版 `settings.env.txt` 仍可读取；保存到新配置不会删除旧文件，分享文件前请自行移除其中的明文密钥。

当前源码的本地通信认证及窗口隔离说明见 [开发文档：安全边界](docs/DEVELOPMENT.md#安全边界)。

## 常见Q&A

- **点击翻译后窗口会消失？** 当前翻译先隐藏面板、选区和旧译文，再截图，截图处理完成后恢复。这是为了确保OCR不会受到干扰。
- **OCR强化会改编OCR窗口位置吗？** 不会，是在原box上重新识别，一般气泡读取问题可以解决，但是气泡本身识别错的话这个也改不了。
- **开启翻页检测后，漫画滚动可能卡顿。** 当前实现会定期截取选区并比较画面，以判断是否翻页。这会带来额外的屏幕捕获和图像处理开销。截图耗时较长时，可能影响滚动流畅度。开销不可避免，但并非每台电脑都会出现明显卡顿。若阅读时不流畅，可切回 **固定** 模式，关闭自动检测，在翻页后手动清除旧译文并点击 **翻译选区**。翻页检测需要 Windows 10 2004 或更新版本，只提示翻译新页，不会自动调用付费翻译。
